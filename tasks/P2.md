## Requirements
### R1 fs.watch 增量（`src/indexer.ts`、`src/config.ts`）
- `startWatcher()`：`fs.watch(join(claudeDir,"projects"), {recursive:true})`，任何事件后 `WATCH_DEBOUNCE_MS = 500` 防抖再跑一次 `indexAll()`（串行防重入，与定时器共用同一把锁）。
- 定时器改为兜底：`RESCAN_INTERVAL_MS = 60_000`。watch 启动失败（如 EMFILE）→ `console.error` 一次并把定时器改回 `10_000`。
- `indexAll()` 返回值不变；`server.ts` 启动时同时启 watcher 与定时器，`stop()` 关闭两者。

### R2 dataVersion 与 ETag（`src/db.ts`、`src/server.ts`、`public/index.html`）
- `meta.data_version`（整数字符串）：`indexAll` 的 `changed > 0`、`mergeOrcaWorkspaceProjects` 合并数 > 0、`refreshProjectMetadata` 更新数 > 0 时 +1。
- live 状态：`createLiveReader` 在缓存刷新且结果与上次不同（sid→status 映射比较）时递增内存计数 `liveVersion`。
- `GET /api/projects` 与 `GET /api/sessions`：响应头 `ETag: "<dataVersion>-<liveVersion>"`；请求 `If-None-Match` 相同 → `304` 空体（仍带 ETag）。`/api/search` 不做 ETag。
- 页面轮询带 `If-None-Match`；304 时不重绘。

### R3 DB 健壮性（`src/db.ts`）
- 打开后执行 `PRAGMA busy_timeout = 5000;`。
- 只在 `schema_version` 缺失或不同时写入。
- 新增 `openDatabaseReadOnly(path)`：文件存在时以 `{ readonly: true }` 打开，不执行任何写（含 PRAGMA journal_mode）；文件不存在返回 `null`。CLI（`focus.ts` 的 `createFocusDeps` 在 `import.meta.main` 路径）使用只读打开。

### R4 CLI 自给自足（`src/focus.ts`）
- `getSessionCwd(sid)`：先查库（若有库）；查不到则在 `<claudeDir>/projects/*/` 找 `<sid>.jsonl`，读前 256 KB，按行 `JSON.parse`，取第一个含字符串 `cwd` 的行。都没有 → `unknown-session`。
- `--dry-run` 额外把"将要执行的命令"以 JSON 行写到 **stderr**（如 `{"plan":["orca","terminal","switch","--terminal","term_…","--json"]}`），stdout 仍只输出 `FocusResult`（契约不变）。

### R5 分组修正（`src/projects.ts`、`src/db.ts`）
- `upsertProject` 改为：`ON CONFLICT(key) DO UPDATE SET root = CASE WHEN projects.root = '' THEN excluded.root ELSE projects.root END`（不再改 name/color）。`refreshProjectMetadata` 仍通过 `updateProjectMetadata` 改 name/color。
- 新增后处理 `mergeDeletedWorktreeProjects(db)`（与 `mergeOrcaWorkspaceProjects` 同时机、同方式 `rewriteProjectKey`）：对每个"cwd 回退"项目 P（`key === root === 某 cwd` 且该 cwd 在磁盘上不存在），若存在另一个项目 R（`root` 非空、非回退、目录存在）满足 `dirname(R.root) === dirname(P.root)` 且 `basename(P.root).startsWith(basename(R.root) + "-")`，则把 P 并入 R。解析顺序仍是 git → `orca/workspaces` 启发式 → cwd 回退；本规则只在后处理里跑，避免依赖文件遍历顺序。
- 本机冻结预期：上面三个目录并入 `lumina`，`/api/projects` 里 `lumina` 的 `sessionCount` 为 **71**，且不再出现 `lumina-scene-language-course-engine-research`、`lumina-release-train-switches`、`lumina-mastra-agent` 三个名字；`mic-sync`（有 git）与 `rc-projects`（无 git，目录存在）保持各自独立。
