### R3 Hermes 源（新 `src/sources/hermes.ts`）
- 用 `bun:sqlite` 的 `new Database(dbPath, { readonly: true })` 打开（文件不存在 → `discover` 返回 `[]`）；`PRAGMA busy_timeout=5000`（只读连接允许）；**不执行任何写 PRAGMA/DDL/DML**。源对象持有该连接（惰性打开），进程退出时可不显式关闭（或在 source 上暴露 `close()` 供 server stop 调用——可选）。
- `discover()`：查询
  ```sql
  SELECT s.id, s.title, s.display_name, s.cwd, s.git_branch, s.started_at,
         s.message_count, COALESCE(MAX(m.timestamp), s.started_at) AS max_ts,
         SUM(CASE WHEN m.role='user' AND m.active=1 AND m.content IS NOT NULL AND m.content!='' THEN 1 ELSE 0 END) AS user_msgs
  FROM sessions s LEFT JOIN messages m ON m.session_id=s.id
  GROUP BY s.id
  ```
  只保留 `user_msgs > 0 OR title/display_name 非空` 的会话（纯空会话跳过）。为每个产出 `SessionFileInfo{agent:"hermes", sid:id, path: dbPath, size: message_count(整数), mtime: round(max_ts*1000)}`。把该行的 `{title,display_name,cwd,git_branch}` 暂存进源内部 `Map<sid, meta>` 供 `deriveSession` 用。
- `deriveSession(info, base)`：
  - 查 `SELECT role, content, timestamp FROM messages WHERE session_id=? AND active=1 AND content IS NOT NULL AND content!='' ORDER BY timestamp`（参数化）。
  - 遍历：`role='user'` 且**非注入**（R 中前缀过滤）→ 计 promptCount、`lastInputAt=round(max(ts)*1000)`、首条设 firstPrompt=`cleanPromptForDisplay(content)`、每条更新 lastPrompt=`cleanPromptForDisplay(content) || 上一次`；同时该 user 文本进 fts（role:"user"）。`role='assistant'` → content 进 fts（role:"assistant"，截 `FTS_TEXT_MAX_CHARS`）。`role='tool'` 跳过。注入 user 消息完全跳过（不计数、不进 fts）。
  - title = `cleanTitle(meta.title ?? meta.display_name)`（非空则用，否则 null；title 不做标签清洗，仅 trim + 截 `DISPLAY_TITLE_MAX_CHARS` 由 db 层 displayTitle 逻辑处理——这里 title 原样存）。
  - 组装 `StoredSession{agent:"hermes", sid, projectKey:(交给 indexer 用 resolveProjectKey(cwd)), cwd:meta.cwd||null, branch:meta.git_branch||null, title, firstPrompt, lastPrompt, lastInputAt, promptCount, filePath: dbPath, fileSize: info.size, fileMtime: info.mtime, parsedOffset:0}`。注意 projectKey 的解析仍由 indexer 统一做（indexer 已在文件流里调用 `resolveProjectKey`）——为复用，`deriveSession` 返回的 session.projectKey 先置 `"unknown"`，indexer 在拿到 derived.session 后用其 cwd 跑 `resolveProjectKey` 覆盖 projectKey（与文件流一致）。
  - fts 文本截 `FTS_TEXT_MAX_CHARS`。
- 导出 `createHermesSource(dbPath): SessionSource`（含 `deriveSession`），以及 `findHermesSessionCwd(sid, dbPath): string|null`（focus 兜底用：只读查 `SELECT cwd FROM sessions WHERE id=?`）。
