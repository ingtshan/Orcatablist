## Requirements

### R1 类型（`src/types.ts`）
```ts
export type GoalStatus = "active" | "done" | "archived";
export interface Goal {
  id: string; name: string; status: GoalStatus; externalRef: string | null;
  color: string | null; createdAt: number; updatedAt: number;
}
export interface GoalSummary extends Goal { sessionCount: number; lastActivityAt: number | null; }
export interface GoalRef { id: string; name: string; }             // 挂在 SessionRow 上
export interface SuggestionReason { code: "branch" | "project" | "title"; label: string; }
export interface SessionSuggestion extends SessionRow { score: number; reasons: SuggestionReason[]; }
```
- `SessionRow` 增加字段（末尾，键必须存在）：`goals: GoalRef[];`（该 session 已确认归属的目标，默认 `[]`）。

### R2 持久库（新 `src/goals.ts`）
- `openGoalsDatabase(path)`：`new Database(path,{create:true})`，`PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA busy_timeout=5000; PRAGMA foreign_keys=ON;`。schema：
  ```sql
  CREATE TABLE IF NOT EXISTS meta (key TEXT PRIMARY KEY, value TEXT);           -- goals_schema_version='1'
  CREATE TABLE IF NOT EXISTS goals (
    id TEXT PRIMARY KEY, name TEXT NOT NULL, status TEXT NOT NULL DEFAULT 'active',
    external_ref TEXT, color TEXT, created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL);
  CREATE TABLE IF NOT EXISTS goal_links (
    goal_id TEXT NOT NULL REFERENCES goals(id) ON DELETE CASCADE,
    agent TEXT NOT NULL, sid TEXT NOT NULL, kind TEXT NOT NULL,                 -- 'confirmed' | 'dismissed'
    created_at INTEGER NOT NULL, PRIMARY KEY (goal_id, agent, sid));
  CREATE INDEX IF NOT EXISTS goal_links_session ON goal_links(agent, sid);
  ```
  - `goals_schema_version` 不匹配时**只做加法迁移**，绝不删库。缺失则写入 '1'。
- `class GoalsStore`（或等价函数集），方法：`createGoal({name,externalRef?,color?})`（id=`crypto.randomUUID()`，created/updated=`Date.now()`）、`updateGoal(id,{name?,status?,externalRef?,color?})`、`deleteGoal(id)`、`getGoal(id)`、`listGoals()`、`setLink(goalId,agent,sid,kind)`（upsert `(goal_id,agent,sid)`）、`removeLink(goalId,agent,sid)`、`confirmedLinks(goalId): {agent,sid}[]`、`excludedLinks(goalId): {agent,sid}[]`（confirmed+dismissed，供排除）、`goalsForSession(agent,sid): GoalRef[]`、`goalsForSessions(pairs): Map<"agent/sid",GoalRef[]>`（批量，供列表）。
- 只在 app 内用 `crypto.randomUUID()` / `Date.now()`（这是应用代码，允许）。

### R3 启发式建议引擎（`src/suggest.ts`，纯函数，可单测）
`suggestSessions(goal, confirmed: SessionRow[], excluded: Set<"agent/sid">, pool: SessionRow[], limit=8): SessionSuggestion[]`
- 候选 = `pool` 中不在 `excluded`、且 `(agent,sid)` 不在 confirmed 里的 session。
- 打分 `score`：
  - `+3` 若 session.branch 非空(且非 "HEAD") 且等于任一 confirmed 的 branch；
  - `+2` 若 session.projectKey 等于任一 confirmed 的 projectKey；
  - `+min(3, sharedTokens)`，`sharedTokens` = `tokens(session.displayTitle + " " + (session.firstPrompt??""))` 与 `goalTokens` 的交集大小，`goalTokens = tokens(goal.name)` ∪ `tokens(每个 confirmed 的 displayTitle)`。
  - `tokens(s)`：小写；提取「长度≥3 的拉丁词」+「CJK 字符的相邻 bigram」；丢弃纯数字与长度<2 的；去重成 Set。
  - confirmed 为空（新目标）时：score 只由「goal.name 的 token 交集」+「projectKey/branch 是否含 goal.name token」驱动——即候选的 projectKey 末段或 branch 命中 goalTokens 也各 `+2/+3`。
- 阈值 `score >= 2`；按 `score desc, lastInputAt desc` 取前 `limit`。
- `reasons`：命中项对应 `{code,label}`，label 用中文（如 `同分支 main`、`同项目 orcatab`、`标题含 “agent”`）。
- 结果**每次按需计算**，不入库。

### R4 服务（`src/server.ts`）—— 装配两个库
- `createServer` 新增打开 `goals.db`（`join(dataDir,"goals.db")`），持有 `goalsStore`；`stop()` 关闭它。
- 路由（全部 `127.0.0.1`，JSON `no-store`；错误 `{error}` + 400/404/500）：
  - `GET /api/goals` → `GoalSummary[]`（sessionCount=confirmed 数；lastActivityAt=这些 session 在 index.db 里的 max lastInputAt；按 lastActivityAt DESC NULLS LAST）。
  - `POST /api/goals` `{name, externalRef?, color?}`（name 必填非空，否则 400）→ 201 + `Goal`。
  - `PATCH /api/goals/:id` `{name?,status?,externalRef?,color?}`（status ∈ GoalStatus）→ `Goal`；不存在 404。
  - `DELETE /api/goals/:id` → `{ok:true}`（级联删连线）；不存在 404。
  - `GET /api/goals/:id` → `{goal, sessions: SessionRow[], suggestions: SessionSuggestion[]}`：sessions=confirmed（用 `db.getSession(agent,sid)` 取回、合并 live、按 lastInputAt DESC，丢弃已不存在于 index.db 的），suggestions=对**全量会话池**（`db.listSessions({limit: 大值如 5000})`，合并 live 非必需）跑 `suggestSessions`。
  - `POST /api/goals/:id/links` `{agent,sid,kind}`（agent∈AGENTS、sid 匹配通用 SID 正则、kind∈confirmed|dismissed）→ `{ok:true}`；goal 不存在 404。
  - `DELETE /api/goals/:id/links/:agent/:sid` → `{ok:true}`。
- `GET /api/sessions` 与 `/api/search`：为每个返回的 SessionRow 填 `goals`（用 `goalsStore.goalsForSessions` 批量，单次查询，勿 N+1）。ETag 逻辑：把 goals 版本纳入——`goalsStore` 维护一个内存 `goalsVersion`（任何写操作 +1），ETag 改为 `"<dataVersion>-<liveVersion>-<goalsVersion>"`。
- `/healthz` 增 `goals: number`（goals 总数），`version` 改 `"p7"`。
- sid 通用校验沿用 P6 的 `SID_PATTERN`。
