- 现状：`SessionRow` 有 `title`（最后一条 ai-title）、`firstPrompt`（首条用户 prompt）、`displayTitle`。`indexer.ts` 的 `applyLines` 已按 prompt 事件累计 `promptCount` 与 `lastInputAt`。缺的是「最近一次用户输入的原文」。
- 现有 `cleanPromptForDisplay(text)` 会去标签、折叠空白、对 `<command-name>` 特殊处理、截到 `FIRST_PROMPT_MAX_CHARS`（200）。复用它，不要新增清洗逻辑。

## Goal
每个会话行在标题下增加一行「最近一次用户输入」预览（`lastPrompt`），区别于作为标题的 `ai-title` 和 `firstPrompt`。

## Requirements

### R1 契约（`src/types.ts`）
`SessionRow` 在 `firstPrompt` 之后、`displayTitle` 之前插入一个键（键必须存在）：
```ts
lastPrompt: string | null;   // 最近一条真实用户 prompt，经 cleanPromptForDisplay；无 prompt 时 null
```
`SearchResult extends SessionRow` 自动带上，无需改。

### R2 索引（`src/indexer.ts`）
- `emptySession` 增加 `lastPrompt: null`。
- `applyLines` 处理 `event.kind === "prompt"` 时：`const cleaned = cleanPromptForDisplay(event.text)`；
  - `firstPrompt`：保持现有逻辑（首条时设，`cleaned || null`）。
  - `lastPrompt`：`cleaned ? cleaned : session.lastPrompt`（每条 prompt 覆盖为最新的非空清洗值；清洗后为空则保留上一次）。
- 其他事件（title/assistant-text/meta）不改 `lastPrompt`。

### R3 存储（`src/db.ts`）
- `StoredSession` 增加 `lastPrompt: string | null`。
- schema `sessions` 表在 `first_prompt` 后增加列 `last_prompt TEXT`（放在 `first_prompt TEXT,` 之后一行）。
- `SCHEMA_VERSION` 从 `"2"` 抬到 `"3"`（结构变更，旧缓存自动重建）。
- `sessionRow(row)`：`lastPrompt: typeof row.last_prompt === "string" && row.last_prompt ? row.last_prompt : null`，放在 `firstPrompt` 之后、`displayTitle` 之前（`displayTitle` 计算不变，仍为 `title ?? firstPrompt?.slice(0,80) ?? sid.slice(0,8)`）。
- `upsertSession`：INSERT 列与占位符、`ON CONFLICT … DO UPDATE SET` 均加入 `last_prompt`（顺序与列定义一致），绑定 `row.lastPrompt`。
- `storedSession(row)` 走 `sessionRow` 展开，自动带上，无需单独改（确认即可）。

### R4 展示（`public/index.html`）
- 在每个会话行的标题（`displayTitle`）下方新增一行 `lastPrompt` 预览：次要色（用现有 `--muted` 变量或与 chips 同级的次要文字色）、单行、`text-overflow: ellipsis` 溢出省略、字号比标题略小。
- 仅当 `lastPrompt` 非空**且** `lastPrompt !== displayTitle` 时渲染（单轮会话里两者常相同，重复则不显示）。
- 搜索态：命中片段（`hits`）已有；`lastPrompt` 预览行**在搜索态不渲染**（避免与片段重复挤占），仅在普通列表渲染。用一个渲染参数或 `if (!isSearch)` 区分。
- 不破坏现有布局：不引入横向滚动，暗色/亮色都要可读。可加一个语义化 class（如 `.row-last-input`）。
- 无障碍：该行是纯文本预览，`title` 属性可放完整 `lastPrompt` 便于悬停查看全文。

### R5 测试（`bun test`；六个核心文件 lines ≥ 80% 不下降）
- `indexer.test.ts`：构造多条 prompt 的会话 → `lastPrompt` 等于最后一条清洗值、`firstPrompt` 等于第一条；最后一条 prompt 清洗后为空（如纯标签）→ `lastPrompt` 保留上一条；无任何 prompt → `lastPrompt` 为 null。
- `db.test.ts`：`upsertSession` + `getSession`/`listSessions` 往返带上 `lastPrompt`；schema v3。
- 若有断言 `SessionRow` 键集合的测试，更新为包含 `lastPrompt`。
